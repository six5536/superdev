# Security Policy

## Supported versions

superdev is pre-1.0. Security fixes target the **latest release** and the
`main` branch only — older versions are not patched, so upgrade to the latest
release to pick up a fix.

## Reporting a vulnerability

Please report security issues **privately** through GitHub's private
vulnerability reporting:

1. Open the [Security tab](https://github.com/six5536/superdev/security) of the
   repository.
2. Click **Report a vulnerability** to start a private advisory.

Don't open a public issue for a suspected vulnerability. The maintainer will
acknowledge the report and coordinate a fix and a disclosure date with you.
