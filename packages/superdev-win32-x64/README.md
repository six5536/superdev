# @six5536/superdev-win32-x64

Prebuilt `superdev` binary for **win32-x64**. This is an internal artifact of
[`superdev`](https://www.npmjs.com/package/superdev), which installs it
automatically as an optional dependency on a matching machine. Don't depend on
it directly; install `superdev` instead.
