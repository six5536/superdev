# SOKF authoring

- Read and follow the type's schema in `knowledge/schemas/`. If the type has no schema, create a schema based on an existing one, include a conforming example, and list the new schema in `knowledge/schemas/index.md`.
- Before creating a numbered concept, read its destination index, choose the next unused number, and make its path, `id`, and title agree.
- Keep existing `id` and `verified` values unchanged. Never add stamped fields.
- Record derivation materials in `sources`; cite individual claims with keyed footnotes.
- Do not edit generated definition or include blocks.
- Resolve validation findings. If repair moves a concept, use its new physical path.
