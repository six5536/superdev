# Code of Conduct

## Our pledge

We want {{superdev:project-name}} to be a project anyone can take part in.
Everyone involved — contributors, maintainers, and people opening issues — is
expected to help keep it that way.

## Expected behaviour

- Be respectful and constructive.
- Assume good faith; disagree with ideas, not people.
- Keep discussions on topic and harassment-free.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory remarks, and sustained
disruption are not tolerated, in any project space.

## Enforcement

Report conduct issues privately to the maintainers. Reports are handled
confidentially; maintainers may warn, moderate, or ban as proportionate.
