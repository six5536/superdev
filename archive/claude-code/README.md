# Deprecated Claude Code workflow

These files preserve the retired Claude Code skill, provider, hook, and
`superdev run` implementation as historical references. They are not active,
discovered, validated as live skills, or materialized by the content pack.

The last supported workflow revision is `b38646a`, immediately before commit
`a89fa30` retired the run protocol and active Claude assets. The replacement is
the Pi-orchestrated `SCOPE → BUILD → ACCEPT` workflow described by ADR-052.
